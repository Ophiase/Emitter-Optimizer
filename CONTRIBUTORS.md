## Cline — agent

Carried out the 2026 modernization of the repository: the Kanon agent layer,
the move to uv and Python 3.14, the `just` gate, the tests, the `ideas/` map
and the roadmap. Work done under the author's review, in the open, one branch

## How to be added

A pull request that changes the model, the engine or the window adds its
author here, with one line saying what was done. A typo fix does not.
